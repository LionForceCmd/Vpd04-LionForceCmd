# Погодный бот ВКонтакте (OpenWeather API)

Домашний проект по модулю 5: VK-бот через **VKBottle (LongPoll API)** + **OpenWeather API**.
API-модуль вынесен отдельно от логики бота, ключи хранятся в `.env` (без hard code).

## Возможности

- 🌤 **Погода сейчас** — текущая погода по названию города
- 📅 **Прогноз 5 дней** — прогноз с шагом 3 часа
- 📍 **Геолокация** — погода по прикреплённой точке или координатам `55.7558, 37.6173`
- 🌫 **Расширенный режим** — погода + качество воздуха (AQI, загрязнители)
- ⚖️ **Сравнение городов** — сравнение погоды в двух городах
- ℹ️ **Помощь** — список команд

Бот — `frontend`-слой. Вся работа с погодным API инкапсулирована в модуль `openweather/`,
который можно использовать и без бота (см. раздел «Консольное тестирование»).

## Подготовка ключей

1. **OpenWeather API**: зарегистрируйтесь на [openweathermap.org](https://openweathermap.org) →
   профиль → **My API Keys** → **Create Key**. Скопируйте ключ.
2. **VK-бот**: создайте [сообщество ВКонтакте](https://vk.com/groups) →
   **Управление → Сообщения** — включите сообщения сообщества и «Возможности ботов» →
   **Управление → Работа с API → Ключи доступа**: выберите **LongPoll API**, права для сообщений,
   включите **Типы событий → Сообщения** → скопируйте токен.

## Установка и запуск

```bash
# 1. Клонировать репозиторий, затем
python -m venv .venv                # Windows: .venv\Scripts\activate
.venv\Scripts\activate
pip install -r requirements.txt

# 2. Заполнить .env (см. .env.example)
# 3. Для тестирования модуля из консоли
python -m openweather.cli --city Москва
python -m openweather.cli --city Москва --extended
python -m openweather.cli --compare Москва,Анталья

# 4. Запуск бота
python -m bot.main
```

После запуска в терминале появится `loop will be run forever` — бот работает.

## Консольные команды CLI

| Команда | Описание |
| --- | --- |
| `--city <город>` | Текущая погода |
| `--city <город> --extended` | Погода + качество воздуха |
| `--city <город> --forecast` | Прогноз на 5 дней |
| `--lat <широта> --lon <долгота>` | Погода по координатам |
| `--compare <город1>,<город2>` | Сравнение двух городов |

## Обработка ошибок

Модуль определяет собственные исключения: `OpenWeatherAPIError`,
`CityNotFoundError`, `APIConnectionError` — бот переводит их в понятные сообщения.
